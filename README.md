# Install

## Dependence

This project is based on [Ebitengine](https://ebitengine.org/). For more help, visit [Ebitengine Install Documents](https://ebitengine.org/en/documents/install.html).

## Steps

1. Switch to this repository directory
    ```sh
    cd /path/to/hoc-trit
    ```
2. Run an install-script for your current OS
    ```sh
    ./install-script/for-linux.sh
    ```
    Choose the right script.
3. Installation Note
    The script "for-linux.sh" has handle dynamic library dependence problem.
    And you won't encounter dynamic library problem if you're using windows.
    You won't encounter dynamic library problem too because macOS has them built in.
